# 📂 Perlica Local Knowledge Drop Folder

Drop your personal Markdown (`.md`) documents, technical guides, or PDF contracts into this folder.

### 📄 Ingesting PDFs
Use the Discord slash command:
```text
/ingest source_type:pdf target:tenancy_agreement.pdf
```

### 📝 Ingesting Notes
Use the Discord slash command:
```text
/note content:WiFi password for home is Hunter22 title:Home Network
```

### 🐙 Ingesting GitHub Repositories
Use the Discord slash command:
```text
/repo action:sync repo:DanielKoh2004/perlica
```
